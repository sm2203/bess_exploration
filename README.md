# BESS Exploration Study
This repository includes the Jupyter notebook used to conduct an exploratory data analysis of BESS data in previous role as a Data Analyst.
The notebook showcases the following skills:
- python
- matplotlib
- data compilation & ingestion
- data cleaning
- data aggregation
- data modelling
- statistical analysis
- documentation
- research skills
- correlation matrix
- hypothesis testing (A/B testing was done before cleaning the notebook to show final results)

I created a report using the results and presented it to the internal data team to inform future projects.
